# Vera APK

Vera APK is the project space for Vera's Android companion.

## Current status

The current `main` branch is a scaffold. It does not yet contain a production Android application or a qualified mobile runtime.

The project is intended to hold Android-side client code, packaging, device integration, and the contracts needed to connect a mobile companion to Vera without confusing a mobile interface with Vera's core identity or runtime.

## Evidence boundary

Repository existence is not evidence that an APK has been built, installed, selected, or is currently communicating with Vera.
